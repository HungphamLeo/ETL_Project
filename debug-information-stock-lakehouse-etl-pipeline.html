PHẦN III — KIẾN THỨC STACK CÔNG NGHỆ CẦN NẮM

🐻‍❄️ Polars
LazyFrame = query plan, chưa execute; cần .collect()
scan_parquet() → LazyFrame; read_parquet() → DataFrame
Ghi S3: không dùng write_parquet(storage_options) — phải dùng s3fs + PyArrow
pl.concat(frames, how="diagonal") → union với auto schema merge
.cast(dtype, strict=False) → NaN thay lỗi (không raise)
partition_cols=[] trong PyArrow → ValueError; dùng None
🦆 DuckDB
S3 endpoint: SET s3_endpoint='HOST:PORT' — KHÔNG có http://
Extensions: INSTALL httpfs; LOAD httpfs; trước mọi S3 query
hive_partitioning=true → tự đọc cột từ path: ingest_date=2026-07-18/
TRY_CAST(col AS BOOLEAN) → NULL thay lỗi (safe)
REGEXP_REPLACE(str, '^https?://', '') → strip http:// prefix
MinIO: s3_url_style='path', s3_use_ssl=false
🔮 SQLMesh
pre_statements: → inject SQL khi mở DuckDB connection ✓
secrets: → KHÔNG inject vào DuckDB session ✗
Model kinds: FULL (re-execute mỗi lần), INCREMENTAL_BY_TIME_RANGE
env_var('NAME', 'default') → đọc env var trong config templates
plan(auto_apply=True, no_prompts=True) → non-interactive
Gold "skipped": silver chưa tồn tại trên MinIO → chạy bronze+silver trước
🗄️ MinIO / S3
Object storage: không có "thư mục" thực sự — chỉ có object keys
Trailing "/" trong key → object hợp lệ nhưng KHÔNG phải directory
Path-style URL: http://HOST:PORT/BUCKET/KEY
s3fs: client_kwargs={"endpoint_url": "http://HOST:PORT"}
config_kwargs={"signature_version": "s3v4"} — MinIO yêu cầu SigV4
Console: http://localhost:9001 — debug bucket/object browser
🐍 Python Logging
logger.warning("msg: %s", value) → % format ✓
logger.warning(f"msg: {value}") → f-string ✓
logger.warning("msg", obj) → obj BỊ BỎ QUA ✗
exc_info=True → include full traceback trong log
Routing: logger_manager.get_logger("logger.storage_log.duckdb")
Logs: logger_storage/<category>/<name>_error.log
⚙️ YAML Config Pattern
Root: environment: (dict flags) + project_params: (actual config)
Unwrap helper: _params(config) → config.get("project_params", config)
"environment" trong YAML ≠ "environment" trong SQLMesh (2 khái niệm khác)
CLI --env dev → SQLMesh environment string
YAML environment.local: true → runtime flag (local/staging/prod)
Luôn dùng CLI value cho SQLMesh, không đọc từ YAML env block
