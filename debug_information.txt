BUG #1 — LAKEHOUSE_BASE: Sai scheme s3a:// thay vì s3://
────────────────────────────────────────────────────────────
File    : scripts/deploy_full_pipeline.py (dòng 70)
Triệu   : FileNotFoundError / Connection refused khi đọc/ghi Parquet lên MinIO
Nguyên  : LAKEHOUSE_BASE = "s3a://lakehouse" — cả DuckDB httpfs lẫn s3fs đều

           Chỉ dùng s3a:// khi chạy trên Spark + Hadoop classpath.

BUG #2 — S3_ENDPOINT có http:// prefix khiến DuckDB lỗi "//host:port"
────────────────────────────────────────────────────────────
File    : scripts/deploy_full_pipeline.py (dòng 73)
          platforms/processing/sqlmesh/config.yaml (pre_statements)
          platforms/processing/sqlmesh/config/config.yaml (pre_statements)

Nguyên  : .env đặt S3_ENDPOINT=http://localhost:9000

Fix SQLMesh (pre_statements):
           SET s3_endpoint=REGEXP_REPLACE(
             '{{ env_var("S3_ENDPOINT") }}', '^https?://', ''
           );
Bài học : DuckDB httpfs ghép scheme tự động. s3fs/boto3 cần URL đầy đủ với http://.
           Phải tách 2 biến: một cho DuckDB (HOST:PORT), một cho s3fs (http://HOST:PORT).
           REGEXP_REPLACE trong DuckDB SQL có cú pháp: REGEXP_REPLACE(str, pattern, repl)
           Pattern '^https?://' match cả http:// lẫn https://.

PHẦN III — KIẾN THỨC STACK CÔNG NGHỆ CẦN NẮM

────────────────────────────────────────────────────────────
1. POLARS — Lazy DataFrame engine (thay thế Pandas cho big data)
────────────────────────────────────────────────────────────
Key concepts:
  - LazyFrame vs DataFrame: LazyFrame = query plan (chưa execute), DataFrame = data in memory
  - scan_parquet() → LazyFrame; read_parquet() → DataFrame
  - .collect() hoặc .collect(streaming=True) để execute LazyFrame
  - storage_options: dict với keys endpoint_url, aws_access_key_id, aws_secret_access_key
  - pl.concat(frames, how="diagonal") → vertical concat với schema auto-merge
  - .with_columns([...]) → add/replace columns
  - .map_elements(fn, return_dtype=pl.Utf8) → apply Python function per element
  - .cast(dtype, strict=False) → cast với NaN thay lỗi (strict=True raise exception)

Write Parquet lên S3:
  Polars 1.x write_parquet() KHÔNG có storage_options → dùng s3fs + PyArrow:
    fs = s3fs.S3FileSystem(key=..., secret=..., client_kwargs={...})
    pq.write_to_dataset(arrow_table, root_path=path, partition_cols=[...], filesystem=fs)
    pq.write_table(arrow_table, file_obj)  # non-partitioned

Common errors:
  - "Must pass at least one partition column" → partition_cols=[] invalid, dùng None
  - "could not find file" → trailing "/" trên S3 path tạo directory object, không phải file
  - LazyFrame collected without .collect() → "PanicException: called unwrap on None value"

────────────────────────────────────────────────────────────
2. DUCKDB — Analytical SQL engine (embedded, không cần server)
────────────────────────────────────────────────────────────
Key concepts:
  - duckdb.connect(":memory:") → in-memory DB (không persist)
  - duckdb.connect("file.db") → persistent DuckDB file
  - httpfs extension: cho phép đọc/ghi S3/MinIO trực tiếp từ SQL
  - .pl() → trả về Polars DataFrame từ query result
  - .df() → trả về Pandas DataFrame
  - INSTALL extension; LOAD extension; → cài và load extension

S3/MinIO config:
  SET s3_endpoint='HOST:PORT';           -- KHÔNG có http:// prefix
  SET s3_access_key_id='key';
  SET s3_secret_access_key='secret';
  SET s3_use_ssl=false;                  -- MinIO local thường không có SSL
  SET s3_url_style='path';               -- MinIO dùng path-style (không phải virtual-hosted)
  SET s3_region='us-east-1';             -- bất kỳ string nào, MinIO bỏ qua

Đọc Parquet:
  SELECT * FROM read_parquet('s3://bucket/path/**/*.parquet', hive_partitioning=true)
  -- hive_partitioning=true → tự đọc cột từ path như ingest_date=2026-07-18/

TRY_CAST vs CAST:
  CAST(col AS BOOLEAN) → lỗi nếu col không phải boolean
  TRY_CAST(col AS BOOLEAN) → trả về NULL nếu lỗi (safe)

Common errors:
  - "IO Error: Connection error to //host:port" → s3_endpoint có http:// prefix
  - "HTTP Error 403" → sai credentials hoặc bucket không tồn tại
  - "Binder Error: Referenced column not found" → cột trong SQL không có trong Parquet schema
  - "INSTALL failed" → không có internet hoặc DuckDB version mismatch

────────────────────────────────────────────────────────────
3. SQLMESH — Data transformation framework (thay thế dbt)
────────────────────────────────────────────────────────────
Key concepts:
  - Model kinds: FULL (re-execute toàn bộ mỗi lần), INCREMENTAL_BY_TIME_RANGE, VIEW, SEED
  - Environments: "prod", "dev" — tách biệt bảng giữa các environment
  - plan() → tính diff giữa current state và desired state
  - run() → execute models
  - audit() → chạy data quality checks
  - Context(paths=..., gateway=...) → khởi tạo SQLMesh context

config.yaml structure:
  gateways:
    <gateway_name>:
      connection:
        type: duckdb
        database: path/to/file.db
        pre_statements:      ← ĐÚNG: inject SQL trước khi dùng
          - "INSTALL httpfs; LOAD httpfs;"
          - "SET s3_endpoint=...;"
        secrets:             ← SAI cho DuckDB: không inject vào session variables
  default_gateway: <gateway_name>

Template syntax trong config.yaml:
  {{ env_var('VAR_NAME', 'default_value') }}  ← đọc environment variable với default

Model file structure:
  MODEL (
    name schema.table_name,
    kind FULL,
    cron '@daily',
    grain (unique_key_col),
    partitioned_by (col1, col2)
  );
  SELECT ... FROM read_parquet('s3://...')

Common errors:
  - "Plan application failed" → thường là SQL syntax error hoặc S3 không accessible
  - "AttributeError: 'Context' has no attribute 'plan'" → SQLMesh version mismatch
  - Gold SKIPPED: silver data chưa có trên MinIO → chạy bronze+silver trước

────────────────────────────────────────────────────────────
4. MINIO — S3-compatible object storage (local dev)
────────────────────────────────────────────────────────────
Key concepts:
  - Object storage: không có "thư mục" thực sự, chỉ có object keys
  - "Bucket" = container (vd: "lakehouse")

5. S3FS — Python S3 filesystem interface
────────────────────────────────────────────────────────────
Key concepts:
  - s3fs.S3FileSystem → Pythonic interface cho S3/MinIO
  - Sử dụng internally bởi Polars, Pandas, PyArrow khi đọc/ghi S3

Correct initialization cho MinIO:
  import s3fs
  fs = s3fs.S3FileSystem(
    key="ACCESS_KEY",
    secret="SECRET_KEY",
    client_kwargs={
      "endpoint_url": "http://HOST:PORT",  # ← PHẢI có http:// prefix
      "region_name": "us-east-1",
    },
    config_kwargs={
      "signature_version": "s3v4",         # ← MinIO yêu cầu SigV4
    },
  )

Common errors:
  - "403 Forbidden / SignatureDoesNotMatch" → sai signature version, dùng s3v2 với MinIO
  - "Connection refused" → MinIO chưa chạy hoặc sai port
  - "NoSuchBucket" → bucket chưa được tạo (chạy infra/init_lakehouse_storage.py)
  - "endpoint_url" ignored ở top-level → phải đặt trong client_kwargs

8. PYTHON LOGGING — Best practices
────────────────────────────────────────────────────────────
API:
  logger.debug(msg, *args)    # *args là % format: logger.debug("val: %s", val)
  logger.info(msg, *args)
  logger.warning(msg, *args)
  logger.error(msg, *args, exc_info=True)  # exc_info=True → include traceback
  logger.exception(msg)                    # shortcut cho error + traceback

SAIOOOOOO:
  logger.warning("DQ issue", record)  # record bị IGNORE hoàn toàn
  logger.warning("DQ issue", str(record))  # str(record) vẫn bị ignore

ĐÚNG:
  logger.warning(f"DQ issue: {record}")
  logger.warning("DQ issue: %s", record)  # % format

10. PYTHON CLOSURES IN LOOPS — Classic pitfall
────────────────────────────────────────────────────────────
Vấn đề:
  for i in range(3):
      lambdas.append(lambda: print(i))  # BUG: tất cả lambda print 2 (final value)

Fix:
  for i in range(3):
      lambdas.append(lambda i=i: print(i))  # default arg capture

Trong project này (BronzeExecutor._execute_symbol):
  for _step, _fn in [("step1", lambda: fn1()), ("step2", lambda: fn2())]:
      try: _fn()
  # KHÔNG bị lỗi closure vì lambdas được tạo cùng lúc trong list literal,
  # và fn1/fn2 là references đến các method khác nhau (không phải loop variable).
