## 💡 KEY RECOMMENDATIONS

### 1. **Use SQLMesh instead of DBT for this project**
   - ✅ **Why:** Better for incremental models, DuckDB native
   - ✅ **Better API:** Data quality tests built-in
   - ✅ **Simpler:** No need for separate dbt-postgres + Docker

### 2. **DuckDB as compute engine, NOT warehouse**
   - ✅ **For:** Silver transforms, ad-hoc analysis, testing
   - ❌ **NOT:** Replace PostgreSQL (which is serving DB)

### 3. **Polars for small-medium batches, Spark for huge volumes**
   - ✅ **Polars:** Development speed, single-node efficiency
   - ✅ **Spark:** 100M+ rows, distributed processing

### 4. **Prefect handles all orchestration**
   - ✅ **Unified:** One place for all workflows
   - ✅ **Flexible:** Python-native, no YAML config hell

### 5. **PostgreSQL OLAP (not OLTP)**
   - ✅ **Purpose:** Analytical queries for BI/reports
   - ✅ **NOT:** Transaction management

# 1. Bản chất Delta / Lakehouse Architecture

Các khái niệm cốt lõi:

* Delta Lake
* Apache Iceberg
* Apache Hudi

👉 Đây **không phải là engine**, mà là **table format + transaction layer** trên Data Lake.

### Khác biệt chính so với Lambda

| Lambda                   | Delta / Lakehouse          |
| ------------------------ | -------------------------- |
| Batch + Speed tách riêng | Unified processing         |
| Data lake immutable      | Data lake có ACID + update |
| Duplicate logic          | Single pipeline            |
| Serving layer riêng      | Query trực tiếp lake       |

👉 Tư tưởng chính:

> “Data Lake trở thành Data Warehouse”

```text
         ┌────────────┴────────────┐
         ↓                         ↓

     (Spark)                (Trino / Druid)
         ↓                         ↓
                ┌──────────────┐
                │ BI / ML / API│
                └──────────────┘
```

### 6.1 Create file `sqlmesh/models/silver/stock_prices_clean.sql`

```sql
MODEL (
  name silver.stock_prices_clean,
  kind INCREMENTAL_BY_TIME (
    time_column ingest_date
  ),
);

WITH raw_data AS (
  SELECT
    symbol,
    CAST(close_price AS DOUBLE) AS close_price,
    CAST(volume AS BIGINT) AS volume,
    CAST(ingest_date AS DATE) AS ingest_date,
    CAST(ingest_timestamp AS TIMESTAMP) AS ingest_timestamp,
    ROW_NUMBER() OVER (
      PARTITION BY symbol, ingest_date
      ORDER BY ingest_timestamp DESC
    ) as rn
  FROM read_parquet('s3://lakehouse/bronze/stock_prices/date=' || @ds || '/*.parquet')
)

SELECT
  symbol,
  close_price,
  volume,
  ingest_date,
  ingest_timestamp
FROM raw_data
WHERE rn = 1 AND close_price > 0;
```

```sql
MODEL (
  name silver.fact_balance_sheet,
  kind INCREMENTAL_BY_TIME (time_column ingest_date),
  cron '@daily',
  owner 'data_team',
  audits (
    NOT_NULL(columns = (symbol, period_end_date, ingest_date)),
    assert_positive_assets(column = total_assets),
    assert_valid_period(column = period_end_date)
  )
);

WITH raw_data AS (
  SELECT
    symbol,
    CAST(period_end_date AS DATE) AS period_end_date,
    CAST(total_assets AS DOUBLE) AS total_assets,
    CAST(total_liabilities AS DOUBLE) AS total_liabilities,
    CAST(total_equity AS DOUBLE) AS total_equity,
    CAST(ingest_date AS DATE) AS ingest_date,
    CAST(ingest_timestamp AS TIMESTAMP) AS ingest_timestamp,
    batch_id,
    source_system,
    -- Deduplication (Subsystem 8)
    ROW_NUMBER() OVER (
      PARTITION BY symbol, period_end_date
      ORDER BY ingest_timestamp DESC
    ) as rn
  FROM read_parquet('s3://lakehouse/bronze/balance_sheet/date=' || @ds || '/*.parquet')
  WHERE total_assets > 0  -- Basic cleansing (Subsystem 5)
)

SELECT
  symbol,
  period_end_date,
  total_assets,
  total_liabilities,
  total_equity,
  ingest_date,
  ingest_timestamp,
  batch_id,
  source_system
FROM raw_data
WHERE rn = 1;  -- Keep latest record per symbol/period
```

```python
#!/usr/bin/env python3
"""
DuckDB PostgreSQL Sync
======================
Subsystem 19: Fact Provider
Subsystem 23: Recovery & Restartability

Syncs Gold layer data from MinIO Parquet to PostgreSQL OLAP.
Uses DuckDB as high-performance bridge.
"""

import duckdb
import os
from datetime import date
from dotenv import load_dotenv

load_dotenv()

def sync_gold_to_postgres(target_date: str = None):
    """
    Sync Gold marts from MinIO to PostgreSQL.
    
    Args:
        target_date: Date to sync (YYYY-MM-DD), defaults to today
    """
    if target_date is None:
        target_date = date.today().strftime("%Y-%m-%d")
    
    print(f"🔄 Syncing Gold data for date: {target_date}")
    
    # Initialize DuckDB
    con = duckdb.connect(database=':memory:')
    
    # Install and load extensions
    con.execute("INSTALL httpfs; LOAD httpfs;")
    con.execute("INSTALL postgres; LOAD postgres;")
    
    # Configure S3 access
    con.execute(f"""
        SET s3_endpoint='{os.getenv("S3_ENDPOINT")}';
        SET s3_access_key_id='{os.getenv("MINIO_ROOT_USER")}';
        SET s3_secret_access_key='{os.getenv("MINIO_ROOT_PASSWORD")}';
        SET s3_use_ssl=false;
        SET s3_url_style='path';
    """)
    
    # Configure PostgreSQL connection
    pg_uri = f"postgresql://{os.getenv('POSTGRES_USER')}:{os.getenv('POSTGRES_PASSWORD')}@{os.getenv('POSTGRES_HOST', 'localhost')}:{os.getenv('POSTGRES_PORT', '5432')}/{os.getenv('POSTGRES_DB')}"
    
    # Attach PostgreSQL
    con.execute(f"ATTACH '{pg_uri}' AS pg_serving (TYPE POSTGRES);")
    
    try:
        # Sync mart_stock_kpi_daily (idempotent)
        print("📊 Syncing mart_stock_kpi_daily...")
        con.execute(f"""
            DELETE FROM pg_serving.gold.mart_stock_kpi_daily 
            WHERE trade_date = '{target_date}';
        """)
        
        con.execute(f"""
            INSERT INTO pg_serving.gold.mart_stock_kpi_daily
            SELECT 
                symbol, trade_date, close_price, volume, turnover,
                daily_return_pct, ma5_price, ma20_price, turnover_rank_in_market
            FROM read_parquet('s3://lakehouse/gold/mart_stock_kpi_daily/trade_date={target_date}/*.parquet');
        """)
        
        # Get sync stats
        result = con.execute("""
            SELECT COUNT(*) as records_synced 
            FROM pg_serving.gold.mart_stock_kpi_daily 
            WHERE trade_date = ?
        """, [target_date]).fetchone()
        
        print(f"✅ Synced {result[0]} records to PostgreSQL")
        return result[0]
        
    except Exception as e:
        print(f"❌ Sync failed: {e}")
        raise
    finally:
        con.close()

if __name__ == "__main__":
    import sys
    
    target_date = sys.argv[1] if len(sys.argv) > 1 else None
    try:
        records = sync_gold_to_postgres(target_date)
        print(f"🎉 Sync completed: {records} records")
    except Exception as e:
        print(f"💥 Sync failed: {e}")
        sys.exit(1)
```

```python
#!/usr/bin/env python3
"""
Slack Alerting System
=====================
Subsystem 29: Problem Escalation

Sends alerts to Slack when pipeline fails or data quality issues detected.
"""

import requests
import os
from typing import Dict, Any
from dotenv import load_dotenv

load_dotenv()

def send_slack_alert(
    message: str,
    severity: str = "warning",
    channel: str = "#data-alerts"
) -> bool:
    """
    Send alert to Slack.
    
    Args:
        message: Alert message
        severity: error | warning | info
        channel: Slack channel
    
    Returns:
        True if sent successfully
    """
    webhook_url = os.getenv("SLACK_WEBHOOK_URL")
    if not webhook_url:
        print("⚠️  SLACK_WEBHOOK_URL not configured")
        return False
    
    # Format message with severity
    severity_emojis = {
        "error": "🚨",
        "warning": "⚠️",
        "info": "ℹ️"
    }
    
    emoji = severity_emojis.get(severity, "⚠️")
    formatted_message = f"{emoji} *Lakehouse Alert* {emoji}\n{message}"
    
    payload = {
        "text": formatted_message,
        "channel": channel,
        "username": "Lakehouse Monitor",
        "icon_emoji": ":robot_face:"
    }
    
    try:
        response = requests.post(webhook_url, json=payload, timeout=10)
        response.raise_for_status()
        print("✅ Slack alert sent")
        return True
    except Exception as e:
        print(f"❌ Failed to send Slack alert: {e}")
        return False

def alert_pipeline_failure(flow_name: str, error_message: str):
    """Alert when Prefect flow fails."""
    message = f"""
Pipeline Failure Alert:
• Flow: `{flow_name}`
• Error: {error_message}
• Time: {datetime.now().isoformat()}

Please check Prefect UI for details.
    """.strip()
    
    send_slack_alert(message, severity="error")

def alert_dq_violation(table_name: str, violations_count: int):

    message = f"""
Data Quality Alert:
• Table: `{table_name}`
• Violations: {violations_count}
• Action Required: Check rejected rows

Review SQLMesh audit results.
    """.strip()
    
    severity = "error" if violations_count > 100 else "warning"
    send_slack_alert(message, severity=severity)

# Example usage in Prefect flow
if __name__ == "__main__":
    # Test alert
    alert_pipeline_failure("bronze_ingestion_flow", "API timeout after 3 retries")
```

### Phase 4 Gold Modeling (9 files)

#### [ ] 22. `sqlmesh/models/gold/mart_stock_kpi_daily.sql` (NEW - 150 lines)
**Mục đích:** Main KPI mart (MA5, MA20, daily returns) (Subsystem 20, 14)  
**Logic (from Word):**
```sql
MODEL (name gold.mart_stock_kpi_daily, kind INCREMENTAL_BY_TIME(time_column trade_date));

WITH daily_metrics AS (
  SELECT symbol, ingest_date AS trade_date, close_price, volume,
    LAG(close_price) OVER (PARTITION BY symbol ORDER BY ingest_date) AS prev_close
  FROM silver.stock_prices_clean
),
calculated_kpis AS (
  SELECT *,
    ((close_price - prev_close) / prev_close) * 100 AS daily_return_pct,
    AVG(close_price) OVER (PARTITION BY symbol ORDER BY trade_date ROWS BETWEEN 4 PRECEDING AND CURRENT ROW) AS ma5_price,
    AVG(close_price) OVER (PARTITION BY symbol ORDER BY trade_date ROWS BETWEEN 19 PRECEDING AND CURRENT ROW) AS ma20_price,
    RANK() OVER (PARTITION BY trade_date ORDER BY (close_price * volume) DESC) AS turnover_rank
  FROM daily_metrics
)
SELECT * FROM calculated_kpis WHERE trade_date = @ds;
```

**Mục đích:** DuckDB → PostgreSQL sync (Subsystem 19, 23)  
**Logic (from Word Phase 5):**
```python
def sync_gold_to_postgres():
    con = duckdb.connect()
    con.execute("INSTALL httpfs; LOAD httpfs;")
    con.execute("INSTALL postgres; LOAD postgres;")
    # Configure S3
    con.execute(f"SET s3_endpoint='{S3_ENDPOINT}'")
    # Attach PostgreSQL
    con.execute(f"ATTACH '{pg_uri}' AS pg_serving (TYPE POSTGRES)")
    # Sync (Idempotent)
    con.execute("""
      DELETE FROM pg_serving.gold.mart_stock_kpi_daily WHERE date = @date;
      INSERT INTO pg_serving.gold.mart_stock_kpi_daily
      SELECT * FROM read_parquet('s3://lakehouse/gold/...');
    """)
```
